# 🏆 SPORTX

A modern sports e-commerce website built using Django, Bootstrap, HTML, CSS, and JavaScript.

---

## 📖 About

SPORTX is a full-stack e-commerce web application developed to provide a seamless online shopping experience for sports products. Users can browse products, search, add items to their wishlist and cart, place orders, and manage their profiles through a clean and responsive interface.

---

## ✨ Features

- User Authentication (Register/Login/Logout)
- Product Catalog
- Product Categories
- Product Search
- Product Reviews & Ratings
- Wishlist
- Shopping Cart
- Checkout & Order Placement
- Order History
- Inventory Management
- Responsive Design
- Admin Dashboard
- Toast Notifications
- Custom 404 Error Page

## 🚀 Installation

```bash
git clone https://github.com/aniesh0312/SPORTX.git

cd SPORTX

pip install -r requirements.txt

python manage.py migrate

python manage.py runserver
```
